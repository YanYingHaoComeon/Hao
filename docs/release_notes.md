# Version 0.1.0

Initial generic source release: seven-module architecture, configuration-driven binary classification, training-restricted MICE, LASSO/Boruta selection, seven model factories, repeated nested CV, complete-per-imputation evaluation, calibration/threshold/DCA utilities and positive-class SHAP. Includes synthetic tests and five audit reports. Project code uses MIT; citation/archival metadata are supplied without a fabricated DOI.

Supported initial schema is numeric continuous plus binary categorical predictors. Multilevel encoding, treatment-specific rules and time-to-event models are outside this release's supported interface. Source output directories are private; trained objects and statistical outputs are not part of the release.
