# Source and licensing boundaries

This repository contains newly written, disease-independent orchestration and library interfaces. Restricted template or original study scripts are excluded rather than assigned a new license. Historical research figures, data, model objects, fixed study variable lists and original Git history are also excluded. Source-format examples were used only to identify the requested plain-source format.

MIT applies to the authored Hao source. Python and R dependencies are installed separately, are not vendored, and remain governed by their own licenses. In particular, the R scientific packages have their own distribution terms; this repository does not relicense those packages. No third-party promotional text, contact information or font assets are included.

The algorithmic definitions are stated in README and implemented as explicit source procedures. This generic framework is not a claim of bitwise reproduction of an earlier research analysis, a clinical software certification, or independently validated prediction performance.
